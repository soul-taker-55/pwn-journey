# 📚 Resources — PWN Journey

Study materials for the journey, organized by phase. Each phase file lists its
sources with a **Focus on** line (what to extract) and a **What I learned** field
(fill it after you study it — proof of absorption, not just a saved link).

> Pattern per module: pwn.college (lecture + challenges) → INE (depth) → book (anchor)
> → solve the challenges → write it up in the repo.

## The three free pillars (independence from AI)
1. **pwn.college** — the spine: lectures + graded challenges → https://pwn.college
2. **Nightmare** — written walkthroughs on real CTF binaries → https://guyinatuxedo.github.io
3. **ROP Emporium** (ROP) + **how2heap** (heap) — targeted practice for the two hardest phases.
