# الدرس 01: المؤشّرات (Pointers)

> **المرحلة:** 0 · **القسم:** 01 · **المدة التقديرية:** 2–3 ساعات

## 🎯 هدف الدرس
أن تفهم ما هو **المؤشّر (Pointer)** فعلياً على مستوى الذاكرة — لا كتعريف نظري، بل أن ترى في ذهنك ماذا يحدث في الذاكرة عند كل سطر. هذا المفهوم هو حجر الأساس لكل ما يأتي بعده في التخصّص كلّه.

## 🧩 المتطلّب السابق
معرفة أساسية بلغة C (المتغيّرات، الدوال، الطباعة بـ `printf`). لا يلزم أكثر من ذلك.

---

## 📖 الشرح

### الذاكرة عبارة عن صناديق مرقّمة
تخيّل ذاكرة الحاسب (RAM) كشارع طويل من الصناديق، كل صندوق يحمل **رقماً** فريداً يُسمّى **العنوان (Address)**، وبداخله **قيمة (Value)**.

حين تكتب `int x = 42;`، يحجز الحاسب صندوقاً، يضع فيه القيمة `42`، ويسمّيه `x`. لكن لهذا الصندوق أيضاً عنواناً رقمياً (مثلاً `0x7ffe1234`).

### المؤشّر = صندوق يخزّن عنوان صندوق آخر
**المؤشّر (Pointer)** متغيّر عادي، لكنه بدل أن يخزّن قيمةً كـ `42`، يخزّن **عنوان** متغيّر آخر. أي أنه "يشير" إلى مكان في الذاكرة.

```c
int x = 42;        // متغيّر عادي قيمته 42
int *p = &x;       // مؤشّر p يخزّن عنوان x
```

- `&x` تعني: "**عنوان** x" (الرمز `&` = خذ العنوان).
- `int *p` تعني: "p مؤشّر يشير إلى عدد صحيح (int)".
- `*p` تعني: "**القيمة الموجودة في العنوان الذي يشير إليه p**" (الرمز `*` = اذهب إلى حيث يشير — تُسمّى العملية dereference، أي "فكّ الإشارة").

### 🖼️ رسم توضيحي

```
      المتغيّر x                     المؤشّر p
   ┌─────────────┐              ┌──────────────┐
   │ العنوان:    │              │ العنوان:     │
   │ 0x7ffe1234  │              │ 0x7ffe5678   │
   ├─────────────┤              ├──────────────┤
   │ القيمة: 42  │◄─────────────┤ 0x7ffe1234   │
   └─────────────┘   يشير إلى   └──────────────┘

   x    == 42            (القيمة نفسها)
   &x   == 0x7ffe1234    (عنوان x)
   p    == 0x7ffe1234    (p يخزّن عنوان x)
   *p   == 42            (اذهب إلى العنوان الذي في p، فتجد 42)
```

النقطة الجوهرية: `p` و `x` صندوقان مختلفان لهما عنوانان مختلفان. لكن **محتوى** `p` هو **عنوان** `x`. لذا حين "تفكّ الإشارة" بـ `*p`، تصل إلى `x` نفسه.

### التعديل عبر المؤشّر
بما أن `*p` تصل إلى `x` فعلياً، فإن الكتابة عبرها تغيّر `x`:

```c
*p = 99;    // هذا يغيّر x نفسه إلى 99!
printf("%d", x);   // يطبع 99
```

هذه القدرة — تعديل متغيّر عبر عنوانه لا عبر اسمه — هي بالضبط ما يستغلّه المهاجم لاحقاً.

---

## 💡 لماذا يهمّ هذا في الـ PWN؟
تخصّص الـ PWN كلّه قائم على **التلاعب بالذاكرة عبر عناوينها**. كل ثغرة سنتعلّمها لاحقاً — من الـ Buffer Overflow إلى الـ Use-After-Free — جوهرها: جعل البرنامج يقرأ أو يكتب في عنوان لم يكن يُفترض أن يلمسه. من لا يفهم المؤشّرات فهماً عميقاً، لا يستطيع أن يفهم أي ثغرة بعدها. هذا الدرس ليس "مقدّمة C" عابرة — إنه العدسة التي سترى بها المجال كلّه.

## ✅ تحقّق من فهمك
قبل الانتقال، أجب لنفسك:
1. ما الفرق بين `p` و `*p` و `&x`؟
2. لو كان `p` يشير إلى `x`، فماذا يفعل السطر `*p = *p + 1;` بقيمة `x`؟
